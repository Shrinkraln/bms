1. 确定基本环境：cubemx+vscode
    1. 不使用keil有卡顿
    2. cubemx生成工具链选择cmake
    3. 补充安装arm-none-eabi-gcc编译和openocd烧录
2. cmake下的基本编译流程
    1. 添加配置文件<a>./.vscode</a>
    2. 编译烧录

```powershell
cmake --preset Debug#配置生成构建系统
cmake --build build/Debug
openocd -f interface/stlink.cfg -f target/stm43g4x.cfg -c "program build/Debug/bms_proj.elf verify reset exit"
```

3. 添加组件

```json
# Add sources to executable
target_sources(${CMAKE_PROJECT_NAME} PRIVATE
    # Add user sources here
    App/Src/bms_main.c
)

# Add include paths
target_include_directories(${CMAKE_PROJECT_NAME} PRIVATE
    # Add user defined include paths
    App/Inc
)
```
