# I2C 设备地址表（7-bit）

I2C1 总线（PB6/PB7，100 kHz 标准模式建议起步）。

| 器件 | 7-bit 地址 | 8-bit 写 / 读 | 备注 |
|---|---|---|---|
| **BQ7692003PWR** (BQ76920) | `0x08` | `0x10 / 0x11` | **强制 CRC**，每字节后跟 CRC8 (poly=0x07)。代码已实现。 |
| **BQ34Z100PWR-G1** | `0x55` | `0xAA / 0xAB` | 上电前需 PB9 (VEN) = 高。 |
| **INA226AIDGSR** | `0x40` | `0x80 / 0x81` | A0=GND, A1=GND。 |
| **TMP117AIDRVR** | `0x48` | `0x90 / 0x91` | ADD0=GND。 |

## 期望 ID 寄存器读出值

| 器件 | 寄存器 | 期望值 | 含义 |
|---|---|---|---|
| BQ34Z100 | Control(0x0001) → 0x00 LE | `0x0100` | Device Type |
| INA226 | 0xFE | `0x5449` | "TI" |
| INA226 | 0xFF | `0x2260`/`0x2261` | Die ID（含 rev） |
| TMP117 | 0x0F | `0x0117` (低 12 位) | Device ID |

## 常见排查

- 扫描扫不到任何设备 → 检查 SCL/SDA 上拉电阻（4.7k 到 3V3）、I2C 速率。
- 只扫到 INA/TMP 扫不到 BQ76920 → BQ76920 可能没上电（B+ 没接电池组）。
- 扫到 BQ76920 但读寄存器一直 CRC 错 → 您手上的丝印不一定是 `BQ7692003`（强制 CRC），可能是 `BQ7692000/01/02`（无 CRC）。如果是后者，把 `bq76920.c` 里的 CRC 字段去掉即可（保留 reg+data，不发 CRC 字节）。
