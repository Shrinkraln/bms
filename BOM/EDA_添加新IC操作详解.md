## 阶段 2：添加 INA226（30 分钟）

### 2.1 搜索元件

EDA 顶部菜单：`元件库` 或快捷键 `Shift+F`

在搜索框输入：

```
C8859
```

确认找到 **INA226** （MSOP-10 封装），双击拖到原理图上。

### 2.2 修改位号

刚拖出来的元件位号是 `U?`，双击元件打开属性：

| 属性 | 改为 |
|---|---|
| 位号 (Designator) | `U_INA` |
| 元件名 | INA226 |
| 封装 | MSOP-10 (默认) |

### 2.3 元件位置摆放建议

把 U_INA 放在 **BQ76920 附近**（一般在 Rsns 采样电阻旁），方便后续 PCB 布局时走线短。

### 2.4 连线（10 个引脚）

INA226 引脚定义：

| Pin | 名称 | 接什么 | 网络名 |
|---|---|---|---|
| 1 | VS | 3V3 + 100nF 退耦 | `3V3` |
| 2 | SCL | I²C 时钟 | `I2C_SCL` |
| 3 | SDA | I²C 数据 | `I2C_SDA` |
| 4 | GND | 地 | `GND` |
| 5 | A0 | 接 GND（设地址 0x40）| `GND` |
| 6 | A1 | 接 GND（同上）| `GND` |
| 7 | ALERT | 悬空（或可选接 STM32）| 不连或 NC |
| 8 | IN- | 经过 R9_INA(10Ω) 接 Rsns PACK 侧 | `SRN_INA` |
| 9 | IN+ | 经过 R8_INA(10Ω) 接 Rsns 电池侧 | `SRP_INA` |
| 10 | VBUS | 监测 PACK+ 电压（可选）| `PACK+` 或 NC |

**操作步骤**：

1. **Pin1 (VS)**：
   - 从 Pin1 引出一条线
   - 放置一个 `3V3` 电源符号（菜单 `放置 → 电源端口`）
   - 在线上加一颗 100nF 退耦电容（搜元件 100nF 0805 → 拖一颗）→ 电容另一端接 `GND` 符号

2. **Pin2 (SCL)**：
   - 从 Pin2 引线
   - 放网络标签 `I2C_SCL`（菜单 `放置 → 网络标签`）

3. **Pin3 (SDA)**：
   - 同上，标签 `I2C_SDA`

4. **Pin4 (GND)**：放 `GND` 符号

5. **Pin5 (A0) + Pin6 (A1)**：都引线到 `GND` 符号（地址 = 0x40）

6. **Pin7 (ALERT)**：
   - 如果不用，放置 `NC` 标记（菜单 `放置 → NC 不连接`）
   - 或者放标签 `INA_ALERT` 备用

7. **Pin8 (IN-)**：
   - 从 Pin8 引线 → 加一颗电阻 → 设位号 R9_INA，阻值 10Ω
   - R9_INA 另一端放标签 `SRN_INA`

8. **Pin9 (IN+)**：
   - 从 Pin9 引线 → 加一颗电阻 → 设位号 R8_INA，阻值 10Ω
   - R8_INA 另一端放标签 `SRP_INA`

9. **跨接 C_INA (1µF)**：
   - 在 R8_INA 和 R9_INA 之间，添加一颗 1µF 0805 电容
   - 一端接到 R8_INA → INA226 Pin9 这条线（即 INA 内侧）
   - 另一端接到 R9_INA → INA226 Pin8 这条线（INA 内侧）
   - 位号 C_INA

10. **Pin10 (VBUS)**：
    - 选项 A（推荐）：放 `NC` 不连接，简化电路
    - 选项 B：通过 100kΩ 分压到 PACK+，监测总线电压

### 2.5 连接到 Rsns

`SRP_INA` 和 `SRN_INA` 是新增的两个网络名。在原理图中找到 Rsns（10mΩ 采样电阻）：

```
原 Rsns 焊盘:
  电池侧 ── 已有: SRP_NET (BQ76920) + SRP_BQ34 (BQ34Z100)
  PACK 侧 ── 已有: SRN_NET (BQ76920) + SRN_BQ34 (BQ34Z100)

需要新增:
  电池侧再引出一根线 → 标签 SRP_INA
  PACK 侧再引出一根线 → 标签 SRN_INA
```

**操作**：
1. 找到 Rsns 元件
2. 从 Rsns 的电池侧引脚（左焊盘）再画一根新线 → 标 `SRP_INA`
3. 从 Rsns 的 PACK 侧引脚（右焊盘）再画一根新线 → 标 `SRN_INA`

EDA 自动认为同名标签连通，所以这样和 INA226 那边的网络就连上了。

### 2.6 完成检查

INA226 完成后，在 EDA 工具栏检查：
- ✅ 元件位号 U_INA
- ✅ 8 个引脚都有连接（Pin7、Pin10 可以悬空）
- ✅ R8_INA、R9_INA、C_INA 都有标注阻值

## 阶段 6：添加 OPA2188（60 分钟，最复杂）

OPA2188 是双路运放（一颗 IC 内部 2 个独立运放），分别控制充电和放电闭环。

### 6.1 搜索元件

```
搜索：C58695
```

找到 **OPA2188** （SOIC-8 封装），双击放置。

### 6.2 元件信息

| 属性 | 值 |
|---|---|
| 位号 | `U_OPA` |
| 封装 | SOIC-8 |

### 6.3 位置

放在 **DAC8552 旁 + Q1/Q2 MOS 之间**（信号链最短）。

### 6.4 引脚定义

| Pin | 名称 | 用途 |
|---|---|---|
| 1 | OUT_A | 运放 A 输出 → Q1 (DSG) Gate |
| 2 | IN-_A | 运放 A 反相输入（电流反馈点）|
| 3 | IN+_A | 运放 A 同相输入（DAC_OUT_A 设定值）|
| 4 | V- | 负电源（接 GND）|
| 5 | IN+_B | 运放 B 同相输入（DAC_OUT_B 设定值）|
| 6 | IN-_B | 运放 B 反相输入（电流反馈点）|
| 7 | OUT_B | 运放 B 输出 → Q2 (CHG) Gate |
| 8 | V+ | 正电源（接 5V0）|

### 6.5 反馈电阻网络（关键）

OPA 误差放大器需要**反馈电阻**和**补偿电容**：

```
DAC_OUT_A (设定电压 0-3.3V)
   │
   ├──── R_OPA_IN_A (10kΩ) ──── OPA Pin3 IN+_A
                                  │
                                  ▼
                              OPA 内部比较
                                  ▲
                                  │
INA226 反馈电流 (转成电压) ──── R_FB_A1 (10kΩ) ──── OPA Pin2 IN-_A
                                                      │
                                                      └── R_FB_A2 (100kΩ) ── OPA Pin1 OUT_A
                                                          (反馈电阻,设定增益)
                                                      
                                                      └── C_COMP_A (100pF) ── 与 R_FB_A2 并联
                                                          (补偿电容,稳定性)

OPA Pin1 OUT_A ──── R_GATE_A (1kΩ) ──── Q1 (DSG) Gate
                    (栅极限流,保护 MOS)
```

具体阻值（**Week 2 我会重新计算精确值**，先用这组安全值）：

| 位号 | 阻值 | 用途 |
|---|---|---|
| R_OPA_IN_A | 10kΩ | DAC 输入限流 |
| R_FB_A1 | 10kΩ | 反馈输入电阻 |
| R_FB_A2 | 100kΩ | 反馈电阻（决定增益 = 11 倍）|
| C_COMP_A | 100pF | 补偿电容（稳定性）|
| R_GATE_A | 1kΩ | 栅极限流 |

**B 通道（充电）的电阻同 A 通道**：

| 位号 | 阻值 |
|---|---|
| R_OPA_IN_B | 10kΩ |
| R_FB_B1 | 10kΩ |
| R_FB_B2 | 100kΩ |
| C_COMP_B | 100pF |
| R_GATE_B | 1kΩ |

### 6.6 连线步骤（A 通道为例，B 通道照做）

**Pin1 (OUT_A) - 输出到 Q1 Gate**：

```
OPA Pin1 ── R_GATE_A (1kΩ) ── 标签 DSG_GATE
            (DSG_GATE 网络已存在,会自动连到 Q1 Gate 和 R19)
```

**Pin2 (IN-_A) - 反馈输入**：

```
OPA Pin2 ──┬── R_FB_A1 (10kΩ) ──── 标签 I_FEEDBACK (来自 INA226 测的电流)
           │
           ├── R_FB_A2 (100kΩ) ──── OPA Pin1 (反馈到输出,形成闭环)
           │
           └── C_COMP_A (100pF) ──── OPA Pin1 (与 R_FB_A2 并联)
```

**Pin3 (IN+_A) - 同相输入（设定值）**：

```
OPA Pin3 ── R_OPA_IN_A (10kΩ) ──── 标签 DAC_OUT_A
```

**Pin4 (V-) 接 GND，Pin8 (V+) 接 5V0**：

```
Pin8 ──── 5V0 + 100nF 退耦
Pin4 ──── GND
```

**B 通道（Pin5/6/7）**：照 A 通道方法画。Pin7 输出经过 R_GATE_B 接到 `CHG_GATE`。

### 6.7 关于 I_FEEDBACK 网络

I_FEEDBACK 是从 INA226 输出的电流测量信号。但 **INA226 是数字 I²C 输出**，不是模拟电压——这是个问题。

**两种解决方案**：

#### 方案 X：用 INA226 模拟输出（不推荐）

INA226 没有模拟输出，所以这个方案不行。

#### 方案 Y：直接用 Rsns 上的压降做反馈（推荐）

```
不经过 INA226,直接用 OPA 自己的差分输入测 Rsns 压降:

Rsns 电池侧 ──── R_FB_A1a (10kΩ) ──── OPA Pin2 IN-_A
Rsns PACK 侧 ──── R_FB_A1b (10kΩ) ──── OPA Pin3 IN+_A (差分输入)
                                       
DAC_OUT_A ──── R_OPA_IN_A (10kΩ) ──── 加到 IN+_A 端 (合并求和)

工作原理:
  OPA 比较 Rsns 上的压降 (= I × 10mΩ) 和 DAC 设定值
  闭环让两者相等 → 实际电流 = DAC 设定的电流
```

这种**差分输入闭环**比**用 INA226 数字反馈**简单很多——OPA 直接读 Rsns 模拟电压，闭环响应快（µs 级），不依赖 STM32。

INA226 仍然在那（用于显示和软件层面校准），但**闭环不依赖它**。

### 6.8 简化版连接（推荐）

考虑你的工期紧，**简化版**：

```
A 通道 (放电闭环):
  DAC_OUT_A ──── R1 (10kΩ) ──── OPA IN+_A (设定电压)
  Rsns 电池侧 ──── R2 (10kΩ) ──── OPA IN-_A (实际反馈, 跨压)
  Rsns PACK 侧 ──── R3 (10kΩ) ──── OPA IN+_A
  R_FB (100kΩ) 跨 OPA Pin1 (OUT) 和 Pin2 (IN-)
  C_COMP (100pF) 与 R_FB 并联
  OPA Pin1 ──── R_GATE (1kΩ) ──── Q1 Gate (经过原 R19 下拉)
  
B 通道 (充电闭环): 同样结构,接 Q2
```

这种**差分电流采样自带闭环**的设计更简单，**电阻总数从 10 颗降到 6 颗**。

**Week 2 我画详细原理图给你**，到时候按那个画。

## 阶段 7：LCD 接口扩到 14P（20 分钟）

3.5" 触摸屏比 1.8" 多需要：触摸 SPI（4 信号）+ 中断 + SD 卡（可选）。

### 7.1 删除原 10P 排母

找到原 LCD 接口（10P 排母 J_LCD），整体删除。

### 7.2 添加 14P 排母

```
搜索：C124379  (1×14 母排针 2.54mm)
```

放置位置同原 LCD 接口。

### 7.3 引脚定义（按淘宝主流 3.5" SPI 触摸屏布局）

| Pin | 网络名 | 用途 |
|---|---|---|
| 1 | `GND` | 地 |
| 2 | `3V3` | 3.3V 电源 |
| 3 | `LCD_CS` (PB1) | LCD 片选 |
| 4 | `LCD_RST` (PB2) | LCD 复位 |
| 5 | `LCD_DC` (PB0) | LCD 数据/命令 |
| 6 | `LCD_MOSI` (PA7) | SPI MOSI |
| 7 | `LCD_SCK` (PA5) | SPI SCK |
| 8 | `3V3` | LCD 背光（直接接 3V3 或经 100Ω 限流）|
| 9 | `LCD_MISO` | SPI MISO（触摸读取用）|
| 10 | `TOUCH_CS` (PC0) | 触摸片选 |
| 11 | `TOUCH_INT` (PB11) | 触摸中断 |
| 12 | `TOUCH_BUSY` | 触摸忙信号（可选）|
| 13 | NC | 不接 |
| 14 | NC | 不接 |

**说明**：
- 你买的 LCD 模组实际引脚顺序可能不同（厂家而定），**到货后必须核对实物丝印**
- 如果你的模组没有触摸功能，Pin9-12 全部 NC
- 如果有触摸但你不用，Pin10-12 NC

### 7.4 主控母排针引脚修改

需要新增两个网络名：

```
PB11 (原 L610_RXD) → 改名为 TOUCH_INT
PC0 (新引出)       → 改名为 TOUCH_CS

★ 注意: PC0 之前可能没引出到母排针,需要在母排针上添加这个引脚
```

**操作**：
1. 找到原 PB11_L610_RXD 标签 → 改名 `TOUCH_INT`
2. 在主控母排针上找到 PC0 引脚的位置（按板子丝印对应）→ 引出一根线 → 标签 `TOUCH_CS`
3. 如果原来 PC0 没引出，要在母排针那一侧添加这个引脚的连接

### 7.5 LCD MISO（Pin9）

LCD MISO 来自触摸屏控制器（XPT2046 或类似），需要接到 STM32 的 SPI MISO 引脚（PA6）：

```
PA6 (原 L610_RESET, 已释放) → 改名 LCD_MISO
```

但是 **PA6 之前你已经用作 DAC_DIN 了**！这里有冲突。

**修订**：

| 信号 | 引脚（修订版）|
|---|---|
| DAC_DIN | **PB12 → 错!PB12 是 KEY1** |
| **DAC_DIN** | **PA1 (原备用)** |
| LCD_MISO | **PA6** |

或者更简单，**把 LCD 的触摸功能砍掉**：

| 选项 | 操作 |
|---|---|
| 砍触摸 | 只用 LCD 显示，按键操作（PB12-15 已经有 4 颗按键）|
| 保留触摸 | 引脚分配重新协调 |

**建议**：**先砍触摸功能**——LCD 只显示数据，操作用现有 4 颗按键完成。这样：
- LCD Pin9-12 全部 NC
- DAC_DIN 用 PA6
- PB11 / PC0 留作备用

**后期有时间再加触摸**。

### 10.2 关键布局原则

| 原则 | 操作 |
|---|---|
| **Rsns 6 路开尔文** | 焊盘加宽，6 个引出点呈三组对称分布 |
| **大电流路径** | B+/B-/PACK+/PACK- 走线 ≥ 5mm 宽 |
| **OPA 与 MOS 距离短** | OPA 输出到 MOS Gate ≤ 10mm |
| **DAC 与 OPA 紧邻** | 减少模拟信号干扰 |
| **REF3033 紧贴 DAC** | 基准电压走线 ≤ 5mm |
| **I²C 走线** | 同时走，差分对（SCL/SDA 并行）|
| **退耦电容紧贴 IC** | 每颗 100nF 距离对应 IC ≤ 3mm |

## 常见问题

### Q1：找不到立创编码对应的元件？

A：搜索栏改用元件名（如 INA226、TMP117 直接搜），或者点击立创编码链接打开商城页面，看页面右侧"EDA 元件库"是否有对应符号。

### Q2：网络名标错怎么办？

A：双击网络标签 → 修改文字。**所有同名标签会自动同步**——这是 EDA 的核心机制。

### Q3：删除的元件再加回来？

A：可以从历史记录恢复（Ctrl+Z），或者重新搜索元件再放置。

### Q4：DRC 报错"未连接引脚"？

A：每个元件的每个引脚必须有连接（接到导线或显式标 NC）。即使是不用的引脚，也要放一个 NC 标记。

### Q5：原理图错了能直接改 PCB 吗？

A：不能。**永远先改原理图 → 重新导出网表 → 更新 PCB**。这样保证两边一致。
