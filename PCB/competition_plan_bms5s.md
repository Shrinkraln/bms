## 五、核心技术亮点 (答辩加分点)

### 1. HRTIM 皮秒级 PWM (184ps 分辨率)
```
传统定时器:   16-bit @170MHz → 分辨率 5.8ns
HRTIM:        12-bit + 32x DLL → 分辨率 184ps (31倍提升)
效果: MOSFET 线性区控制精度 ↑, 输出纹波 ↓
```

### 2. 双闭环架构: 数字 PI + 模拟 OPA
```
数字环: MCU PI 控制 → DAC8552 (16-bit) → 设定电流基准
模拟环: OPA2188 (零漂移 0.03μV/°C) → 高速误差放大 → MOSFET 栅极
优势: 数字精度 + 模拟速度, 兼顾 mAh 准确性和瞬态响应
```

### 3. CMSIS-DSP 实时 FFT 谐波分析
```
采样: INA226 1kHz → DMA 缓冲 1024 点
FFT: arm_rfft_fast_f32 → 512 频点
输出: 基波 + H2~H9 谐波幅值, THD 百分比
应用: 电池化成过程异常检测 (析锂/微短路产生特征谐波)
```

### 4. TMP117 温度补偿 Coulomb 计数
```
mAh = Σ(I × Δt) / 3600 × k_temp
k_temp = 1 + α(T - 25°C)  // TMP117 ±0.1°C → 容量误差 ±0.05%
```

### 5. 四象限工作能力
```
象限 1: CC/CV 充电 (化成)        Q1 PWM + Q2 ON
象限 2: CC/CR/CP 放电 (测试)     Q1 ON + Q2 PWM
象限 3: 反向充电 (电池反接保护)   (保护功能)
象限 4: 能量回馈 (预留)          (同步整流扩展)
```

## 八、风险与应对

| 风险 | 概率 | 应对 |
|------|------|------|
| PCB 打样周期超期 | 中 | 旧板飞线先行调试, 新版到位后直接替换 |
| LCD TouchGFX 移植困难 | 中 | 降级方案: 用现有简单 UI (线/条图), TouchGFX 后续迭代 |
| HRTIM 配置复杂 | 低 | STM32CubeG4 有 HRTIM 例程, G474 已有成熟参考 |
| MOSFET 线性区发热 | 中 | 加装散热片, 限制最大放电功率, 软件热保护 |
| CMSIS-DSP 内存不足 | 低 | G474 有 128KB SRAM, 1024-pt FFT 需 ~16KB |
