## 修改依赖关系

```
修改顺序:  ① ──→ ② ──→ ③ ──→ ④ ──→ ⑤ ──→ ⑥ ──→ ⑦→⑧→⑨→⑩
           │      │      │      │      │      │      └─可选──┘
           │      │      │      │      │      │
依赖:      无     无     无     无     ⑤需   ⑥需
                                 评估   确认
                                 再改   电路
```

**①→②→③ 互相独立**，可以同时修改（不同电路区域），但建议按序验证。

**④ 依赖 ①**：因为 I2C 器件包括 BQ34Z100，需要先确认 BQ34 CE 正常才能验证 I2C 通信。

**⑤ 需要先评估**：确认 OPA2188 补偿网络的设计意图后再决定是否修改栅极电阻。
