### 1.7 功率铜皮连接（手工画）

```
走线: B+ (PWR类, ≥3mm)
  F2.pin2 → Rsns.pin1
  路径: 从 (15, 8) 到 (21, 10)
  方法: 用多边形铜皮, 宽 ≥3mm, 网络=B+

走线: $2N586 (PWR类, ≥3mm)
  Q4.Tab → Q2.Tab
  路径: 直接大铜皮连接 (39, 10) 到 (45, 10)
  方法: 多边形铜皮, 宽 ≥3mm, 网络=$2N586

走线: PACK- (PWR类, ≥3mm)
  Q2.S → U16.pin1
  路径: (48, 6) 到 (65, 6)
  方法: 宽铜皮 ≥3mm, 网络=PACK-

走线: SRN_INA 功率段 (手工 ≥3mm)
  Rsns.pin2 → Q4.S
  路径: 从 Rsns 右侧焊盘到 Q4 下方引脚
  方法: 宽铜皮连接, 网络=SRN_INA
  ★ Kelvin 支路从 Rsns.pin2 端头单独引出 10mil 细线
```
