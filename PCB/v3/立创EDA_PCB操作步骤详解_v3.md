## 1. 工程创建与网表导入

### 1.1 新建 PCB 工程

```
操作路径: 文件 → 新建 → PCB

步骤:
  ① 打开立创 EDA 专业版
  ② 点击左上角「文件」→「新建」→「PCB」
  ③ 命名为: BMS5S_v3_PCB_2026-06-12
  ④ 保存到: D:\coding_codes\bms\PCB\v3\
```

### 1.2 导入网表

立创 EDA 专业版 **不能直接导入 `.tel` 网表**。需要在原理图中完成修改后, 通过「原理图转 PCB」功能同步。

**正确操作流程:**

```
步骤:
  ① 确认原理图 (SCH) 已按 v3 网表修改完毕
     (参考 modification_topology_final.md 中的 F1~S4 修改)
  
  ② 在原理图编辑器中:
     「设计」→「原理图转 PCB」
  
  ③ 如果已有 PCB 文件:
     「设计」→「更新 PCB」→ 选择目标 PCB 文件
     → 勾选「更新元件」+「更新网络」→ 执行
  
  ④ 检查导入日志:
     - 所有封装必须匹配 (Footprint not found = 错误)
     - 所有网络必须连通 (NC 引脚确认设计意图)
```

### 1.3 导入后验证

```
验证清单:
  □ 元件数量: 约 90 个 (对照 BOM)
  □ BQ34Z100 CE: U3.2 在 PB9_BQ76_BOOT 网络 (不是 PB9)
  □ INA226 VBUS: U_INA.8 在 B+ 网络
  □ R17.1/R18.1: 在 3V3 网络 (不是 BQ_3V3)
  □ R_EN2_U7: 18kΩ (不是 10kΩ)
  □ R_GATE_A/R_GATE_B: 4.7kΩ (不是 1kΩ)
  □ C1: 100nF (不是 1μF)
```

## 2. 板框设置

### 2.1 板框概述

**100×100mm 是嘉立创优惠价上限**, 建议维持此尺寸以控制成本。

### 2.2 绘制板框

```
操作路径: 放置 → 板框 (Board Outline)

步骤:
  ① 切换到「板框层」(Board Outline Layer)
  
  ② 点击「放置」→「矩形」
     或按快捷键: 工具栏选「矩形」工具
  
  ③ 在画布上绘制 100mm × 100mm 矩形:
     - 起点: (0, 0)
     - 终点: (100, 100)
  
  ④ 精确设置尺寸:
     - 选中矩形边框
     - 右侧属性面板:
       X: 0 mm
       Y: 0 mm
       宽度: 100 mm
       高度: 100 mm
  
  ⑤ 拐角处理:
     - 可选圆角 R=3mm (美观, 减少应力集中)
     - 属性面板 → 拐角半径: 3mm
```

### 2.3 安装孔

```
操作路径: 放置 → 过孔 (设置为 NPTH) → 或使用「安装孔」封装

步骤:
  ① 放置 4 个 M3 安装孔 (SCREW1~SCREW4):
     封装: M3螺丝 (网表中已定义)
     孔径: 3.2mm
     外径: 6.0mm
     类型: NPTH (非金属化孔)
  
  ② 四个角位置 (距板边 5mm):
     SCREW1: X=5,   Y=5    (左下)
     SCREW2: X=95,  Y=5    (右下)
     SCREW3: X=5,   Y=95   (左上)
     SCREW4: X=95,  Y=95   (右上)
  
  ③ 安装孔接 GND (如需要):
     - 如果是金属化孔 (PTH): 直接连接到 GND 网络
     - 如果是 NPTH: 在孔周围放一个环形焊盘接 GND
     **本设计建议: 4 个安装孔通过大焊盘接 GND**
```

### 2.4 工艺边 (可选)

```
如果元件靠板边 <2mm, 需要加工艺边:

步骤:
  ① 在板框外 +5mm 画工艺边 (V-Cut 线)
  ② 工艺边上放 MARK 点 (光学定位点)
  ③ 导出 Gerber 时包含工艺边层

本设计元件不多, 100×100 有充足空间, 通常不需要工艺边。
```

### 2.5 禁止布线区 (Keepout)

```
操作路径: 放置 → 禁止区域 (Keepout)

需要设置 Keepout 的区域:
  ① 安装孔周围: 半径 3mm (禁止布线+放置元件)
  ② 板边向内 0.5mm (防止 V-Cut 伤及铜皮)
  ③ FPC 连接器下方 (如有)

步骤:
  ① 切换到「Keepout 层」
  ② 画圆/矩形覆盖禁区
  ③ 右键 → 属性 → 勾选「禁止布线」+「禁止放置元件」
```

### 3.3 立创 EDA 层叠设置步骤

```
步骤:
  ① 「设计」→「层叠管理器」
  
  ② 层数: 选择「4 层」
  
  ③ 设置每层属性:
     - 顶层 (Top):    类型=信号层
     - 内层1 (Mid1):  类型=平面层(负片) — 用于 GND
     - 内层2 (Mid2):  类型=平面层(负片) — 用于电源分割
     - 底层 (Bottom): 类型=信号层
  
  ④ 铜厚:
     - 顶层/底层: 1oz (35μm) — 立创 EDA 默认
     - 内层:      0.5oz (17μm) — 立创 EDA 默认
     **如需功率区 2oz, 需在投板备注中说明**
  
  ⑤ 介质厚度:
     - 保持默认 (通常 2116 PP ~0.12mm)
  
  ⑥ 点击「确定」
```


## 6. 铺铜规则

### 6.1 铺铜策略

```
┌──────────┬──────────────────────────────────────────┐
│ 层        │ 铺铜策略                                   │
├──────────┼──────────────────────────────────────────┤
│ Top       │ 空白区域铺 GND 铜皮                        │
│           │ 功率区不铺 (保留宽走线 + 开窗加锡)          │
├──────────┼──────────────────────────────────────────┤
│ Mid1      │ **整层铺 GND (完整平面, 不分割)**           │
├──────────┼──────────────────────────────────────────┤
│ Mid2      │ 分割铺铜: 3V3 / 5V0 / B+ / REF_3V3       │
│           │ 各区域保持 ≥1mm 间距                       │
├──────────┼──────────────────────────────────────────┤
│ Bottom    │ 空白区域铺 GND 铜皮                        │
│           │ 功率路径补充铜皮 (增加载流)                 │
└──────────┴──────────────────────────────────────────┘
```

### 6.2 铺铜参数设置

```
立创 EDA 铺铜参数:

  网络:           GND (Top/Bottom/Mid1), 对应电源 (Mid2)
  间距到走线:     10mil (Top/Bottom), 15mil (Mid1 外圈)
  间距到焊盘:     10mil
  间距到过孔:     8mil
  间距到板框:     20mil
  热焊盘连接:     十字连接 (Thermal Relief)
    十字宽度:     20mil
    十字间距:     20mil
  最小铜皮宽度:   10mil (避免细铜皮脱落)
  移除死铜:       是 (Remove Dead Copper)
  平滑等级:       中
```

### 6.3 操作步骤

```
① 点击工具栏「铺铜」工具 (或快捷键 Shift+F)
② 沿板框画出铺铜轮廓 (内缩 20mil)
③ 选择铺铜网络: GND
④ 设置参数 (按 6.2)
⑤ 点击「确定」

重复:
  ⑥ Mid1: 整层铺 GND (网络=GND)
  ⑦ Mid2: 分别铺:
     - 3V3 区域 (网络=3V3)
     - 5V0 区域 (网络=5V0)
     - B+ 区域 (网络=B+)
     **各区域重叠处留 1mm 间距**
```

### 6.4 热焊盘 Thermal Relief 说明

```
对于直接连接大铜皮的焊盘, 必须使用十字连接:
  功率焊盘 (Rsns, MOSFET, B+端子): 十字宽度 ≥40mil (4 条)
  普通焊盘:                         十字宽度 20mil

操作:
  选中焊盘 → 属性 → 热焊盘 → 自定义
  → 十字宽度: 20mil
  → 十字间距: 20mil
```

## 7. 元件布局操作

### 7.1 布局前准备

```
① 设置栅格:
   视图 → 栅格 → 设置栅格
   电气栅格: 5mil
   显示栅格: 50mil
   元件栅格: 25mil

② 飞线显示:
   打开「网络飞线」显示 (快捷键: Ctrl+Shift+N)
   密集区可暂时关闭部分飞线以减少干扰

③ 打开「元件参考点」显示
```

### 7.2 布局顺序 (按优先级)

```
第 1 步: 先锁定 (Fix) 接插件位置
  - J1 (CAN 端子) → 板右边
  - USB1 (Type-C)  → 板右边
  - U2 (电池端子)  → 板底边
  - U16 (输出端子) → 板底边
  - U4 (LCD FPC)   → 板顶边
  - SW1 (按键)     → 板右下 (方便按压)

第 2 步: 摆放功率回路 (最优先)
  - F2 → Rsns → Q4 → Q2 → U16 沿一条直线
  - 方向: 左→右 或 下→上
  - Q4 和 Q2 留 5mm 间距 (散热)

第 3 步: 摆放模拟前端
  - INA226 靠近 Rsns (<15mm)
  - OPA2188 靠近 MOSFET 栅极 (<20mm)
  - DAC8552 靠近 OPA (<20mm)
  - REF3033 紧贴 DAC8552
  - BQ76920 + BQ34Z100 放在模拟安静区
  - TMP117 远离热源

第 4 步: 摆放电源树
  - MP1584 + L1 + D4 回路最小化
  - AMS1117 靠近 MP1584
  - 电源区远离模拟区 ≥10mm

第 5 步: 摆放核心板
  - U6 + U7 居中, 排针朝外
  - 方便引出 I2C/SPI/CAN 到外设

第 6 步: 摆放通信 + 外设
  - TJA1042 靠近 J1
  - CH340G + X1 靠近 USB1
  - LED1/2 + BUZZER1 + SW1
```

### 7.3 立创 EDA 布局操作技巧

```
元件对齐:
  选中多个元件 → 右键 → 对齐 → 左对齐/水平居中/等间距

元件翻转:
  选中元件 → 按 'F' 键 → 翻到底层
  注意: 翻面后丝印也翻面

旋转:
  选中元件 → 按 'Space' → 旋转 90°

锁定元件:
  选中元件 → 右键 → 「锁定」
  已摆好的关键元件锁定, 防止误移动

测距:
  按 'M' 键 → 点击起点 → 点击终点 → 显示距离

3D 预览:
  「视图」→「3D 预览」    检查元件干涉、高度碰撞
```

## 8. 布线操作

### 8.1 布线优先级

```
顺序   网络类           说明
────────────────────────────────────────
1st    Power            功率主回路 — 先布, 其他绕行
2nd    Analog (Kelvin)  Rsns → INA226 — 最敏感
3rd    Analog (REF)     REF_3V3 — 第二敏感
4th    Analog (DAC)     DAC_OUT_A/B — 第三敏感
5th    Gate             DSG_GATE, CHG_GATE
6th    Supply           5V0, 3V3 分配
7th    I2C              SCL, SDA
8th    SPI              SCK 优先, MOSI 次之
9th    CAN              CAN_H, CAN_L 差分
10th   Default          其他低速信号
```

### 8.2 布线操作

```
① 点击「布线」工具 (或按快捷键 'W')
② 点击起始焊盘
③ 移动鼠标, 立创 EDA 自动避让
④ 左键点击确定拐角
⑤ 右键(或双击)完成当前走线

切换层走线:
  走线过程中按 'Tab' 键 → 切换层
  或: 走线过程中点「层」下拉菜单
  换层自动添加过孔

走线角度:
  推荐 45° 拐角 (不做 90° 直角)
  差分线可用「差分对布线」工具

走线宽度切换:
  走线过程中按 'Shift+W' → 选择预设宽度
  或: 右侧属性面板直接输入宽度值
```

### 8.3 关键走线操作细节

#### 8.3a 功率主回路 (B+ → Rsns → MOSFET → PACK-)

```
① 走线宽度: 120mil (3mm)
    在右侧属性面板输入: Width = 120mil

② 如果 120mil 太宽导致无法出线:
    - 用多边形铜皮代替走线
    - 「放置」→「多边形」→ 画功率路径 → 设置网络=B+ / PACK-
    - 边缘用圆弧过渡 (减少 EMI)

③ B+ 主干道:
    B+ 端子 → F2 → Rsns.1 (大铜皮)
    
④ PACK- 主干道:
    Q2.3 → U16 → PACK- 端子 (大铜皮)

⑤ 换层时用 6× 过孔阵列 (28/14mil)
```

#### 8.3b Kelvin 检测线

```
① Rsns.2 → R9_INA (10Ω) → INA226.9 (VIN-)
    宽: 10mil
    长: <20mm
    从 Rsns 焊盘终端直接引出 (不在宽铜皮中间分叉)

② Rsns.1 = GND, INA226 的 VIN+ 通过 Rsns 自身到 GND
    检查: Rsns 是 GND 参考侧, Rsns.2 是电流流入侧

③ 差分走线:
    如果有从 Rsns 两端引出的 SRN/SRP 对:
    选中两条线 → 右键 → 「差分对布线」→ 设置间距 8mil
```

#### 8.3c REF_3V3 基准走线

```
① 走线宽度: 12mil
② 两侧包 GND 铜皮 (或手动加 GND 走线作屏蔽)
    操作: 在 REF_3V3 走线旁边平行走一根 GND 线 (间距 12mil)
③ 长度: <20mm
④ 远离: SW 节点和 L1 ≥15mm
```

#### 8.3d 栅极驱动走线

```
① DSG_GATE:
    U1.1 → R_GATE_A (4.7kΩ) → D2_阴极 → Q4.G
                          └→ D10_阳极 ← U15.1 (OPA_OUT_A)

② CHG_GATE:
    U1.2 → R_GATE_B (4.7kΩ) → D8_阴极 → Q2.G
                          └→ D11_阳极 ← U15.7 (OPA_OUT_B)

③ R19 (10kΩ): Q4.G → SRN_INA (栅源泄放) 在 Q4 近处
④ R20 (10kΩ): Q2.G → PACK- (栅源泄放) 在 Q2 近处

全部 12mil, 尽量短, 距离开关噪声 ≥5mm
```

#### 8.3e I2C 总线

```
① SCL: U6.13 → R17 → U1.5 → U3.13 → U_INA.5 → U_TMP.1
    菊花链 (Daisy Chain) — 不星型分支
    上拉 R17 放在总线中间位置

② SDA: U6.27 → R18 → U1.4 → U3.14 → U_INA.4 → U_TMP.6
    同上

③ 触摸 I2C (独立总线):
    PC8_TF_SCL: U6.10 → R28 → U4.5
    PC9_TF_SDA: U6.9 → R29 → U4.3

④ 注意: 测量 I2C 和触摸 I2C 是两条独立总线
    不要在 PCB 上把它们连通!
```

### 8.4 布线效率技巧

```
① 使用「自动布线」做参考 (不完全依赖):
    「布线」→「自动布线」→ 仅作为评估走线可行性
    检查后全部删除, 手动重新布线

② 批量修改线宽:
    选中多条同网络的走线 → 属性面板 → 统一修改 Width

③ 走线长度显示:
    「视图」→「显示走线长度」

④ 颜色标注网络类:
    每个网络类设置不同颜色 → 快速区分布线进度
    操作: 网络类管理器 → 设置颜色
```

## 9. 过孔与缝合

### 9.1 GND 缝合过孔 (Stitching)

```
目的: 降低 L1↔L2↔L4 GND 阻抗, 减少 EMI

原则:
  - 每 10mm×10mm 区域至少 1 个 GND 过孔
  - 功率区加倍 (每 5mm 1 个)
  - PCB 边缘每隔 10mm 放缝合过孔 (Faraday Cage 效应)

操作:
  ① 在 Top Layer 空白区域放置过孔 (先放一个)
  ② 设置过孔属性:
     外径: 24mil, 内径: 12mil
     起始层: Top, 终止层: Bottom
     网络: GND
  ③ 用「阵列粘贴」批量放置
     「编辑」→「阵列粘贴」
     间距 X: 10mm, 间距 Y: 10mm
     数量: 覆盖全板
```

### 9.2 散热过孔 (Thermal Vias)

```
功率元件下方需要散热过孔阵列:

MP1584 (U5) EP:
  → 9 个 GND 过孔, 3×3 阵列
  → 孔径: 12mil, 间距: 1.2mm

MOSFET (Q2/Q4) Drain Tab:
  → 6 个 B+ (或 $2N586) 过孔, 2×3 阵列
  → 孔径: 16mil/外径 28mil (功率级)

AMS1117 (U11) Tab:
  → 4 个 3V3 过孔, 间距 1.2mm
```
