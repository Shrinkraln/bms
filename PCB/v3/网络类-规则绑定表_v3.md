# BMS-5S v3 网络→规则绑定表（简化版）

> 基于网表: `Netlist_PCB1_2026-06-14.tel`（已逐网络核对一致）
> 规则预设来源: `Config_DesignRule_PCB1_2026-06-15_SIMPLIFIED.json`（基于简化速查 v2.0）
> 简化原则: 同线宽+同过孔+同间距 → 合并为同一类，不因功能名不同而分家

## 一、网络类（Net Class）— 3 个

在立创 EDA 中: `设计 → 网络类 → 新建类 → 添加网络 → 绑定规则`

### 类 1: PWR（功率 + 电源分配 + 开关节点）

```
网络成员:
  —— 大电流功率路径 ——
  B+          电池总线 (3A) → ★ 需手工加宽到 3mm
  PACK-       放电输出负极 (3A) → ★ 需手工加宽到 3mm
  $2N586      MOSFET 共漏节点 (3A) → ★ 需手工加宽到 3mm
  NET1        电池端子 BAT+ → F2 (3A) → ★ 需手工加宽到 3mm
  SRN_INA*    仅「Q4源 ↔ Rsns」功率段 (3A) → ★ 手工加宽

  —— 电源分配 ——
  5V0         MP1584 输出 / 全局 5V 供电
  3V3         AMS1117 输出 / 全局 3.3V 供电
  BQ_3V3      BQ76920 内部 LDO 输出

  —— 开关节点 ——
  $2N559      MP1584 SW 节点 (U5.1 + D4 + L1) → ★ 铜皮面积 ≤50mm²

绑定规则:
  线宽:     Power_1.0mm (39mil)
  过孔:     Power_Via_28x14
  间距:     对 SIG 类 ≥15mil
  铺铜热焊盘: Copper_Power_Thermal_40mil

备注:
  ★ 4 个网络 (B+, PACK-, $2N586, NET1) + SRN_INA 功率段 线宽不足——需在 PCB 上
    手工拉宽铜皮到 ≥3mm。同属 PWR 类不变，仅局部加宽处理，不为 4 个网络单开一类。
  ★ SW 铜皮面积 ≤50mm²——短粗连接 U5.1→D4→L1，不铺大铜皮。
  ★ SRN_INA 是混合网络: Q4源↔Rsns 段走全电流(手工加宽到 3mm),
    其余 Kelvin 采样支路按细线走(10mil)。同一网络两种宽度，必须手工处理。
```

### 类 2: SIG（其余全部信号）

```
网络成员:
  —— 精密模拟 ——
  SRN_INA     Kelvin 采样支路 (Rsns焊盘 → R9_INA/R9_34/R9_76/R_SRN)
  SRN_NET     BQ76920 SRN 滤波后 (U1.19)
  SRN_BQ34    BQ34Z100 SRN 滤波后 (U3.10)
  SRP_NET     BQ76920 SRP 滤波后 (U1.18)
  SRP_BQ34    BQ34Z100 SRP 滤波后 (U3.9)
  DAC_OUT_A   DAC8552 通道A → OPA2188
  DAC_OUT_B   DAC8552 通道B → OPA2188
  REF_3V3     REF3033 输出 / DAC8552 基准

  —— 电池采样 ——
  NET2~NET5   电池端子分压
  VC0_NET~VC5_NET  BQ76920 Cell 电压检测

  —— 通用模拟 ——
  NTC1_AIN    BQ76920 温度检测
  BQ76_BAT    BQ76920 BAT 电压检测

  —— 栅极驱动 ——
  DSG_GATE    Q4 放电 MOSFET 栅极
  CHG_GATE    Q2 充电 MOSFET 栅极

  —— I2C 总线 ——
  I2C_SCL     测量总线时钟 (4 设备: BQ76+BQ34+INA+TMP)
  I2C_SDA     测量总线数据
  PC8_TF_SCL  触摸屏独立 I2C 时钟
  PC9_TF_SDA  触摸屏独立 I2C 数据

  —— SPI 总线 ——
  PA5_LCD_SCK / PA6_LCD_MISO / PA7_LCD_MOSI / PB0_LCD_DC / PB1_LCD_CS / PB2_LCD_RST
  PB10_DAC_CS / PB13_DAC_SCL / PB15_DAC_MOSI

  —— CAN / USB ——
  CAN_H, CAN_L / UD+, UD- / D+, D-

  —— UART ——
  PA2_UART_DBG_TX / PA3_UART_DBG_RX

  —— 数字 IO + 中断 ——
  PA0_TOUCH_RST / PA8_TOUCH_INT / PA11_CAN_RX / PA12_CAN_TX
  PB4_LED_GREEN / PB5_LED_RED / PB8_BUZZER_CTRL / PB9_BQ76_BOOT / PB12_KEY1
  BQ76_ALERT / CH_V3 / CC1 / CC2

  —— 晶振 ——
  CH_XI / CH_XO

绑定规则:
  线宽:     Signal_10mil (10mil)
  过孔:     Signal_Via_24x12
  间距:     默认 10mil (与同类走线、GND 之间)

备注:
  旧版 13 个类 (Power_Cell, Analog_Precision, Analog_General, Gate, I2C, SPI,
  CAN, USB, UART, Digital_IO, Oscillator, Supply 的 REF_3V3 部分) 全部共用
  「10mil + 24×12 via」→ 合并为 SIG。
  ★ 测量 I2C 和触摸 I2C 是两条独立总线，不可连通。
  ★ SRN_INA Kelvin 支路从 Rsns 焊盘单点引出(星形)，不要从功率铜皮中间分接。
```

### 类 3: GND（地 — 不走线，只铺铜）

```
网络成员:
  GND         全局地

绑定规则:
  线宽:     无限制 (不走线, 只用铺铜 + 过孔)
  过孔:     Signal_Via_24x12 (缝合), Power_Via_28x14 (功率区)
  铺铜:     L1/L4 铺 GND, L2 完整 GND 平面（不切槽！）
```

## 二、网络→网络间距规则 — 2 条

在立创 EDA 中: `设计 → 设计规则 → 添加 → 类型「网络-网络」`

```
┌──────────────────────┬──────────────────────┬──────────┬──────────────────┐
│ 源                    │ 目标                  │ 最小间距  │ 规则名            │
├──────────────────────┼──────────────────────┼──────────┼──────────────────┤
│ PWR 类全部网络        │ SIG 类全部网络         │ 15mil    │ PWR_to_SIG       │
│ 其余所有情况           │ 其余所有情况           │ 10mil    │ Default          │
└──────────────────────┴──────────────────────┴──────────┴──────────────────┘
```

> **旧版 27 条 → 2 条，合并分析：**
>
> | 旧版规则 | 处理方式 |
> |----------|----------|
> | SW→REF_3V3(40) / SW→DAC(30) / SW→Kelvin(25) / SW→I2C(20) / SW→默认(15) | → PWR→SIG 统一 15mil |
> | B+→I2C(20) / B+→SPI(20) / B+→CAN(20) / B+→IO(15) | → PWR→SIG 统一 15mil |
> | PACK-→I2C(20) / PACK-→SPI(20) / $2N586→I2C(15) / VC5→数字(15) | → PWR→SIG 统一 15mil |
> | REF_3V3↔SW(40，冗余) / REF_3V3→数字(12) | → PWR→SIG 15mil 覆盖 SW→REF; REF→数字由 Default 10mil 覆盖 |
> | CAN_H↔CAN_L(8) / UD+↔UD-(8) / D+↔D-(8) / CH_XI↔CH_XO(6) | → Default 10mil 覆盖 |
>
> **SW→精密模拟 15mil 精度验证：**
> L1 层 SW 与 REF_3V3 平行走线，15mil 间距、并行走线长度 5mm：
> 寄生电容 ≈0.08pF → 500kHz 耦合电流 ≈120nA → REF_3V3 对地阻抗 ≈3mΩ(去耦电容)
> → 耦合噪声 ≈0.4μV ≪ DAC8552 1LSB(50μV)。
> **前提：(1) 物理分区保证走线不平行长距离 (2) 去耦电容紧贴 IC。**

## 三、区域规则 — 1 个

在立创 EDA 中: 先在 PCB 画规则区域 → `设计 → 设计规则 → 添加 → 类型「区域」`

```
┌──────────────────┬──────────────────────┬──────────────────────────────┐
│ 区域名             │ 条件                  │ 约束                          │
├──────────────────┼──────────────────────┼──────────────────────────────┤
│ Analog_Quiet     │ 覆盖: INA226 +        │ 禁止: PWR 类网络进入           │
│                  │ OPA2188 + DAC8552 +   │ 允许: SIG, GND               │
│                  │ REF3033 + BQ76920 +   │                              │
│                  │ BQ34Z100 + TMP117    │                              │
└──────────────────┴──────────────────────┴──────────────────────────────┘
```

> 旧版 4 区域 → 1 区域。删除的 3 个：
> - Power_Loop_Zone → 功率区由线宽(3mm 手工)和 PWR→SIG 15mil 自动约束
> - Noisy_Switch_Zone → SW 铜皮面积由人工控制(≤50mm²)，PWR→SIG 15mil 已阻止其他信号靠近
> - MCU_Digital_Zone → 数字信号不需要特殊保护

## 四、特殊处理清单（不设规则，人工执行）

| # | 操作 | 原因 |
|---|------|------|
| ① | **Kelvin：从 Rsns 焊盘端头引出** | 共享功率铜皮 → 5% 测量误差 |
| ② | **D2/D8 紧贴 MOSFET 栅极 <5mm** | 寄生电感延迟 TVS 钳位 |
| ③ | **B+/PACK-/$2N586/NET1 + SRN_INA 功率段 手工加宽到 ≥3mm** | 3A 持续电流，1mm 不够 |
| ④ | **去耦电容 100nF 距 IC 电源引脚 <5mm** | 寄生电感使高频去耦失效 |
| ⑤ | **SW 铜皮面积 ≤50mm²**（仅 U5.1→D4→L1） | 超过则辐射显著增加 |
| ⑥ | **I2C 菊花链不星型；测量 I2C 和触摸 I2C 独立** | stub 反射 + 地址冲突 |

## 五、立创 EDA 操作顺序

```
第 1 步: 导入规则预设
  设计 → 设计规则 → 导入
  → 选择 Config_DesignRule_PCB1_2026-06-15_SIMPLIFIED.json
  → 此时已有: 间距矩阵 + 线宽预设 + 过孔预设 + 热焊盘预设

第 2 步: 创建网络类（3 个）
  设计 → 网络类 → 新建
  → PWR: 添加 §一.类1 全部网络 → 绑定 Power_1.0mm + Power_Via_28x14
  → SIG: 添加 §一.类2 全部网络 → 绑定 Signal_10mil + Signal_Via_24x12
  → GND: 添加 GND → 不绑定线宽

第 3 步: 设置间距规则（2 条）
  设计 → 设计规则 → 添加（网络-网络类型）
  → PWR_to_SIG: PWR类 ↔ SIG类 ≥15mil
  → Default: 其余所有 ≥10mil

第 4 步: 绘制 Analog_Quiet 区域
  PCB 上画规则区域覆盖模拟区 → 命名 Analog_Quiet →
  设计 → 设计规则 → 添加（区域类型）→ 禁止 PWR 类进入
```
