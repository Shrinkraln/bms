## 2. 层叠结构设计

### 2.1 推荐方案: 4 层板

```
层序    名称              用途                          铜厚
─────────────────────────────────────────────────────────
L1      TOP (元件面)      信号 + 功率走线 + 元件          1oz (可局部 2oz)
L2      GND (地层)        完整地平面, 不分割              1oz
L3      PWR (电源层)      3V3/5V0/B+ 分割 + 信号          1oz
L4      BOTTOM (底面)     信号 + 辅助功率                 1oz

板厚: 1.6mm
板材: FR-4 TG135 (标准) 或 TG150+ (推荐 — 应对焊接热)
```

### 2.2 层叠理由

- **L2 完整地平面**: 关键! 为所有信号提供低阻抗返回路径; INA226/OPA2188 精密模拟电路需要完整参考面
- **L3 电源分割**: 将不同电源域隔离, 避免干扰耦合
- **4 层 vs 2 层**: 4 层板的 EMI 比 2 层板低 15-20dB, 对精密模拟测量至关重要

### 2.3 电源层 (L3) 分割方案

```
┌─────────────────────────────────────────────┐
│                    GND  (L2 完整, 不分割)      │
├──────────┬──────────┬──────────┬────────────┤
│  3V3     │  5V0     │  B+      │  REF_3V3   │
│  (数字)   │  (模拟)   │  (功率)   │  (基准)    │
│          │          │          │            │
│ MCU区    │ OPA区    │ MOSFET区  │ DAC区      │
│ LCD区    │ CAN区    │ Rsns区   │ REF区      │
│ I2C区    │ UART区   │ MP1584区 │            │
└──────────┴──────────┴──────────┴────────────┘
```

**注意:** L3 分割仅用于直流分配 — L2 GND 始终保持完整, **不要在 L2 上切槽**。

```
│  │  (板中央) │  │  + TMP117    │  │  + REF3033         │   │
│  │          │  │  + BQ76920   │  │  (板左下方)         │   │
│  │          │  │  + BQ34Z100  │  │                    │   │
│  └──────────┘  └──────────────┘  └────────────────────┘   │
│  ┌──────────────────────────────────────────────────────┐  │
│  │  ③ 电池端子 + 保险丝 + BAT 滤波  (板底部边缘)         │  │
│  └──────────────────────────────────────────────────────┘  │
└────────────────────────────────────────────────────────────┘
```

### 3.2 分区优先级 (先摆哪个)

| 优先级 | 区域 | 原因 |
|--------|------|------|
| **P0** | ① 功率回路 | 决定整板热管理和 EMI — 必须先定位置 |
| **P1** | ② 模拟前端 | 需要靠近功率回路测量点, 远离噪声源 |
| **P2** | ③ 电池端子 | 大电流入口, 决定功率流向 |
| **P3** | ④ 电源树 | 靠近 B+, 远离模拟区 |
| **P4** | ⑤ 核心板 | 居中, 方便引出到各外设 |
| **P5** | ⑥ LCD | 板边缘, 方便安装 |
| **P6** | ⑦ 通信接口 | 板边缘, 方便插接 |

### 3.3 板框建议

- **尺寸**: 建议 80mm × 60mm 或 100mm × 65mm (根据核心板 + LCD 尺寸确定)
- **安装孔**: 4× M3 螺丝孔 (SCREW1~4), 孔径 3.2mm, 外径 6mm, 接 GND
- **定位**: 安装孔放四角, 距离板边 ≥3mm

## 4. 分区布局细则

### 4.1 区域① — 功率回路 (最优先)

```
信号流向:  B+ → F2 → Rsns → Q4(DSG) → Q2(CHG) → PACK- → U16 (输出端子)

布局要点:
┌─────────────────────────────────────────────┐
│                                              │
│  B+ 端子                                     │
│   │                                          │
│   ▼                                          │
│  F2 (BSMD2920) ──── Rsns (R2512) ──── Q4 ──── Q2 ──── PACK- 端子
│                        │    │          (TO-252)  (TO-252)    │
│                        │    │           │         │          │
│                       SRN  SRP         GATE      GATE      U16
│                       (Kelvin 走线引出)  D2贴栅   D8贴栅
│                                              │
│  ┌──────────────────────────────────────────┘
│  ▼
│  U_INA (INA226)  ──  靠近 Rsns, Kelvin 走线
│
│  U15 (OPA2188)   ──  靠近 MOSFET 栅极
│  U_DAC (DAC8552) ──  靠近 OPA
│  U14 (REF3033)   ──  靠近 DAC
└─────────────────────────────────────────────┘

关键规则:
  ❶ 功率回路面积最小化: B+ → F2 → Rsns → Q4 → Q2 → PACK- → 端子
     这个环路围成的面积要尽量小
  
  ❷ 宽铜皮: Rsns → Q4 → Q2 → PACK- 路径用 ≥3mm 宽铜皮 (或开窗加锡)
  
  ❸ Kelvin 连接: Rsns 的 SRN/SRP 必须从电阻焊盘两端直接引出
     (4-terminal sensing), 不能跟功率电流共用铜皮
  
  ❹ MOSFET 散热: Q2/Q4 TO-252 的 Tab (Drain) 铜皮面积 ≥200mm²
     用作散热; Q2 Tab=$2N586, Q4 Tab=$2N586 (共漏)
  
  ❺ D2/D8 钳位: 紧贴 Q4/Q2 栅极引脚, 距离 <5mm
     D2 阴极 → Q4.G, D8 阴极 → Q2.G
     阳极 → 对应源极 (SRN_INA / PACK-)
  
  ❻ D10/D11 隔离: OPA 输出 → 二极管阴极, 阳 → 栅极
     1N4148WS ×2, 只拉低不推高, 靠近 MOSFET 放置
```

### 4.2 区域② — 模拟前端

```
布局要点:
  ❶ INA226 (U_INA):
     - 尽量靠近 Rsns, Kelvin 走线 <15mm
     - R8_INA/R9_INA (10Ω) 串在 Kelvin 线上, 靠近 U_INA.9/10
     - C21/C22 (100nF) 紧贴 VIN+/VIN- 引脚到 GND
     - VBUS (U_INA.8): 经 R14(100Ω)+C29(100nF) 接 B+
  
  ❷ BQ76920 (U1):
     - 靠近电池分压电阻梯 (R1~R6, 100Ω)
     - Cell 滤波电容 C1~C6 (100nF ×6) 对称排列, 紧贴对应引脚
     - C7 (10μF BAT电容) + C8 (1μF) 靠近 U1.9/10
     - C31 (100nF) + R16 (100Ω) → BQ76_BAT
     - R21 (1MΩ) ALERT 上拉到 3V3 ← 确认: $2N246 中 R21.2 → U1.20
     - 远离 L1 ≥10mm (防磁耦合)
  
  ❸ BQ34Z100 (U3):
     - 靠近 B+ 分压电阻 R22(1.5MΩ)+R23(68kΩ)
     - C12(100nF)+C13(1μF) 电源去耦
     - 远离功率电感 L1 ≥10mm
  
  ❹ TMP117 (U_TMP):
     - WSON-6, EP 必须可靠接 GND (多个过孔到 L2)
     - 远离热源 (MOSFET, LDO, MP1584)
     - 放置在板边缘或通风处, 减少自热偏差
```

### 4.3 区域③ — 电池端子

```
  ❶ 5S 平衡端子 (U2: CONN-TH_6P):
     - NET1~NET5 + B+ 依次排列
     - R2~R6 (100Ω) 靠近端子, 限流保护
     - 每个 Cell 输入 100nF 到 GND (C1~C6 就近)
  
  ❷ 输出端子 (U16: CONN-TH_2P):
     - PACK- + B+
     - 与功率回路连接用宽铜皮 ≥3mm
```

### 4.4 区域④ — 电源树

```
信号流: B+ → MP1584 → 5V0 → AMS1117 → 3V3
                           → REF3033 → REF_3V3

布局要点:
  ❶ MP1584 (U5, SOIC-8-EP):
     - EP 大面积铜皮到 GND (≥9个过孔到 L2 GND)
     - L1 (22μH): 靠近 U5.1(SW pin), SW 节点面积最小化!
     - Cin_U7 (22μF) + Cout_U7 (22μF) 靠近 U5
     - Ccom_U7 (22pF) + R_FB1_U7(105kΩ) + R_FB2_U7(20kΩ) 反馈网络短走线
     - R_FREQ_U7 (500kΩ → 约 500kHz 开关频率): 靠近 FREQ 引脚
     - R_EN1_U7 (100kΩ, 上拉 B+) + R_EN2_U7 (18kΩ, 下拉 GND): EN@15V=1.96V ✅
     - D4 (SMA 肖特基续流二极管): 靠近 SW, 短粗走线
     - C_V1 (10nF) 自举电容: 靠近 U5.8 (BOOST)
      **此区域为全板最大噪声源 — 必须远离模拟区 ≥10mm**
  
  ❷ AMS1117-3.3 (U11, SOT-223):
     - 输入 C17 (10μF) + C24 (100nF), 输出 C18 (22μF) + C19 (100nF)
     - Tab (VOUT) 铜皮面积 ≥100mm² 散热
     - 输入来自 5V0
  
  ❸ REF3033 (U14, SOT-23-3):
     - 输入: 5V0 → C25(4.7μF) + C26(100nF), 紧贴 U14.1
     - 输出: REF_3V3 → C27(100nF) + C28(100nF) (已分布到 3V3 网络)
     - 远离功率电感 L1 ≥15mm
     - 走线避开开关噪声区
     - **REF_3V3 是 DAC8552 的基准 — 任何噪声直接转换为输出噪声**
```

## 5. 布线顺序与规则

### 5.1 布线优先级

| 顺序 | 走线类别 | 说明 |
|------|---------|------|
| **1st** | 功率主回路 | B+ → F2 → Rsns → Q4 → Q2 → PACK- (宽铜皮 ≥3mm) |
| **2nd** | Kelvin 检测线 | Rsns → INA226 (SRN/SRP 差分，从焊盘端头引出) |
| **3rd** | 敏感模拟线 | DAC_OUT_A/B, REF_3V3（短直，远离 SW） |
| **4th** | GND 过孔阵列 | 功率区 → L2 GND 的过孔 (低阻抗) |
| **5th** | 电源分配 | 5V0/3V3 走线 |
| **6th** | 其余数字信号 | I2C → SPI → CAN/UART → IO |

### 5.2 各层走线分配

```
L1 (TOP):
  - 功率主回路 (宽铜皮)
  - 所有元件放置
  - 短信号走线
  - 关键模拟走线

L2 (GND):
  - 完整地平面 — 不布线！

L3 (PWR):
  - 电源分割平面 (3V3/5V0/B+)
  - 非关键数字信号

L4 (BOTTOM):
  - 辅助信号走线
  - 补充 GND 铜皮
```

## 6. 关键走线约束

### 6.1 功率主回路

```
路径: B+ → F2 → Rsns → Q4(Drain) → Q4(Source) → $2N586 → Q2(Source) → Q2(Drain) → PACK-

规则:
  线宽:          ≥3mm (手工加宽铜皮; PWR 类默认 1mm 不够)
  环路面积:       最小化 → 去线和回线尽量靠近
  过孔:           换层时用 ≥4 个 28×14 过孔并联
  GND 参考:       L2 完整 GND 紧贴下方
```

### 6.2 Kelvin 检测 (Rsns → INA226)

```
SRN: Rsns.2 → R9_INA(10Ω) → U_INA.9 (VIN-)
SRP: Rsns.1 → GND (通过 Rsns 接 GND)

规则:
  起点:         ★ 从 Rsns 焊盘两端直接引出，不在功率铜皮上分接
  走线:         10mil, SRN/SRP 平行走
  长度:         <20mm
  注意:         SRN_INA 功率段(Q4源↔Rsns) 必须手工加宽到 3mm
```

### 6.3 REF_3V3 + DAC 模拟输出

```
REF_3V3:  U14.2 → C27+C28 → U_DAC.2
DAC_OUT:  U_DAC.4/3 → R_DAC_A/B → U15.3/5 (OPA 同相输入)

规则:
  走线:         10mil, 短且直, 尽量 L1 不换层
  去耦:         C27(100nF)+C28(100nF) 紧贴 U_DAC.2
  远离:         SW 节点 (物理分区保证, PWR→SIG 15mil 规则兜底)
  注意:         4 层板 L2 完整 GND 提供回流路径, 不需要表面包地铜皮
```

### 6.4 I2C 总线

```
测量 I2C:  SCL(U6.13) / SDA(U6.27) → 4 设备 (BQ76+BQ34+INA+TMP)
触摸 I2C:  SCL(U6.10) / SDA(U6.9)  → 触摸屏

规则:
  走线:         菊花链, 不星型分支
  ★ 测量 I2C 和触摸 I2C 是两条独立总线，不可连通
  上拉:         R17/R18/R28/R29 (4.7kΩ)
```

### 6.5 栅极驱动

```
DSG_GATE: U1.1 → R_GATE_A(4.7kΩ) → D2 → Q4.G ← D10 ← U15.1
CHG_GATE: U1.2 → R_GATE_B(4.7kΩ) → D8 → Q2.G ← D11 ← U15.7

规则:
  D2/D8:       ★ 紧贴 MOSFET 栅极 <5mm (TVS 钳位)
  R19(10kΩ):   紧贴 Q4 (栅源泄放)
  R20(10kΩ):   紧贴 Q2 (栅源泄放)
```

### 6.6 其余数字信号 (SPI / CAN / USB / UART / IO / 晶振)

```
全部归入 SIG 类, 10mil + 24×12 via, 默认 10mil 间距。

80×60mm 4 层板 + L2 完整 GND 下:
  - SPI (<40MHz): 不需等长匹配 (5mm 长度差 → 相位差 0.24°)
  - CAN (1Mbps) / USB FS (12Mbps): 不需差分阻抗控制 (走线 < 临界长度 30cm)
  - 晶振 (12MHz): 不需包地 (L2 GND 即天然屏蔽)
  - 去耦电容 100nF: ★ 紧贴 IC 电源引脚 <5mm (必须)
```

## 7. DRC 检查清单

### 7.1 布局阶段

- [ ] 功率回路面积最小化 (目视检查)

- [ ] TMP117 远离热源 (MOSFET/LDO/MP1584)
- [ ] 各 IC 去耦电容紧贴电源引脚 <5mm

## 9. 注意事项速查表

### 9.1 绝对禁止

| ❌ 禁止 | 原因 |
|---------|------|
| L2 GND 切槽分割 | 破坏信号返回路径，不可逆 |
| Rsns Kelvin 在功率铜皮上分接 | 测量误差 5%+ |
| 开关节点 (SW) 大面积铜皮 | EMI 辐射天线 |
| D2/D8 远离 MOSFET 栅极 | ESD 击穿风险 |

### 9.2 必须执行

| ✅ 操作 | 原因 |
|---------|------|
| 功率回路优先布局和走线 | 决定整板性能 |
| B+/PACK-/$2N586/NET1 铜皮 ≥3mm | 3A 载流 |
| 每个 IC 电源引脚配 100nF 去耦 <5mm | 高频旁路 |
| 多打 GND 过孔 (stitching) | 降低 L1-L2 地阻抗 |
| D2/D8 紧贴 MOSFET 栅极 <5mm | TVS 钳位有效 |
| I2C 测量和触摸独立走线 | 地址冲突 + 噪声隔离 |

### 9.3 可选优化

| 💡 优化 | 效果 |
|---------|------|
| 测试点预留 (SCL/SDA/DAC_OUT/REF_3V3/B+) | 方便调试 |
| 功率铜皮开窗加锡 | 增加载流量 |
| 电源 LED 指示 (3V3/5V0) | 调试直观 |
| 模拟区屏蔽罩焊盘 (预留) | 极端噪声环境 |
| ADUM3160 隔离 USB (预留) | 竞赛加分 |
| 版本号+日期丝印 | 迭代追踪 |
